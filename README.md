# Telegram Channel Analyzer

A data-collection and analytics engine for **public** Telegram channels and groups.
It connects to Telegram over MTProto (via [Telethon](https://docs.telethon.dev/)),
collects public metadata and post-level engagement signals, computes a set of
quality metrics and a 0–100 channel **health score**, detects the channel's
topical category, and optionally runs an LLM-based content analysis. Results are
persisted to PostgreSQL and can be exported to CSV.

## What it does

- **Metadata collection** — for a public channel/group it reads title, description,
  subscriber/participant counts, admin count, slowmode, linked-chat settings and
  other public attributes exposed by the Telegram API.
- **Engagement metrics** — samples recent posts and aggregates views, reactions,
  comments and forwards into averages, engagement rate (ERR) and reach
  (views / subscribers). Only aggregates are stored, not message text.
- **Health score (0–100)** — a transparent, weighted score built from signals such as:
  - **bot ratio** in the audience / commenters (lower is better),
  - **posting activity** and frequency,
  - **admin count** and moderation settings,
  - **slowmode** and other configuration flags.
- **Category detection** — a fast keyword-based classifier assigns a topical
  category (news, tech, crypto, education, lifestyle, …) with a confidence score,
  before any paid LLM call.
- **LLM content analysis (optional)** — sends a sample of public post text to an
  LLM (Anthropic Claude directly, or via OpenRouter) to estimate thematic
  classification, sentiment/tonality, content-quality and toxicity scores.
- **Export** — writes results to CSV for downstream analysis. See
  [`data/sample/channels_sample.csv`](data/sample/channels_sample.csv) for the
  output schema (synthetic example data).

## Methodology

1. **Preliminary pass** (cheap, no LLM): resolve the channel, pull public metadata,
   sample recent posts, compute engagement metrics and the health score, and detect
   the category by keywords. This yields a 0–100 preliminary score used to triage
   large channel lists.
2. **LLM pass** (optional, paid): for channels that pass the preliminary triage,
   run a deeper content analysis to produce category / sentiment / quality /
   toxicity signals.

## Exploratory analysis (notebook)

[`notebooks/channel_analysis.ipynb`](notebooks/channel_analysis.ipynb) is a worked
analysis of a channel population — it renders inline on GitHub, no setup needed. It runs on
a **synthetic** 3 000-channel sample generated by
[`notebooks/generate_sample.py`](notebooks/generate_sample.py), whose metrics and scores use
the *same* formulas as the production code (`utils/metrics.py`,
`services/preliminary_scorer.py`), so the relationships are faithful to a real crawl.

Highlights from the sample:

- Audience is a **long tail** — the top 10% of channels hold ~64% of all subscribers.
- **Engagement falls as channels grow** — small channels carry the highest ERR; raw view
  counts flatter large, coasting channels.
- **~8% of channels show a bought-audience signature** (many subscribers, dead reach & ERR,
  or a high bot ratio); the health score's bot discount separates them cleanly — median
  reach 30% vs 7%, median health 56 vs 25.
- A label-free **k-means** pass recovers interpretable archetypes: *healthy niche*,
  *large & coasting*, *vanity / bought*, and *dormant*.

## Stack

- Python 3.11+
- Telethon (Telegram MTProto client)
- SQLAlchemy 2.0 (async) + asyncpg + PostgreSQL
- aiohttp / httpx for HTTP
- Anthropic / OpenRouter for optional LLM analysis
- tenacity for retry logic

## Quick start

```bash
# 1. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure credentials
cp .env.example .env
# edit .env: TELEGRAM_API_ID, TELEGRAM_API_HASH, DATABASE_URL, and (optionally) LLM keys

# 4. Run the cheap preliminary scoring pass on a channel
python run_preliminary.py --session sessions/my_account --channel example_news

# 5. Run the LLM content analysis pass
python run_llm_analysis.py --session sessions/my_account --channel example_news
```

You will need a Telegram API ID/hash from <https://my.telegram.org> and a running
PostgreSQL instance reachable via `DATABASE_URL`.

## Data & ethics

- The tool operates on **public** channels and groups only, using data that
  Telegram already exposes to any regular client.
- **No message content is stored** beyond aggregate metrics (counts, averages,
  scores). Text is only sampled transiently and, if LLM analysis is enabled, sent
  to the configured model to produce aggregate scores.
- No credentials or personal data are included in this repository. All secrets are
  read from environment variables (see `.env.example`).
