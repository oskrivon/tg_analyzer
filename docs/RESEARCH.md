## Решения

### Двухфазный конвейер: дешёвый триаж → платный LLM — (базовое решение проекта)
**Контекст:** LLM-анализ контента дорог; массовый проход по всем каналам экономически невыгоден.
**Решение:** фаза 1 (без LLM) собирает метаданные/вовлечённость, считает health-score и
категорию по ключевым словам; фаза 2 (LLM) включается только для каналов, прошедших триаж.
**Почему:** экономия на порядок за счёт раннего отсева; health-score отделяет накрутку до
дорогого прохода.

### Health-score и метрики на общих формулах — (базовое решение проекта)
**Контекст:** нужен прозрачный, воспроизводимый скор; разведка в ноутбуке должна совпадать с продом.
**Решение:** формулы вовлечённости и health-score живут в `utils/metrics.py` /
`services/preliminary_scorer.py`; ноутбук (`notebooks/`) использует ровно те же формулы на
синтетической выборке.
**Почему:** ноутбук рендерится на GitHub без окружения и остаётся достоверным.
